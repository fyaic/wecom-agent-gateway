## 可复核的维护状态

- 私有状态保留最近周期的真实起止时间、检查前后摘要、最后实际续期动作；后续健康周期不覆盖最后动作。
- 退避周期不伪造新检查时间。`status` 是历史快照，不是实时 GUI、业务 API 或后台进程存活证明。
- 日志保留动作和固定诊断变化，相同健康轮不刷屏；不保存身份、链接、秘密或任意上游诊断文本。
- 动作前耐久意图、单实例锁、未知结果保护保持不变；SIGTERM 等在途轮完成后释放自有锁，不擅自清理遗留锁。

## 自然周期的验收门槛

1. 首先启用仅白名单消息能力的到期维护，预续保持关闭，保留未过期基线。
2. 等真实墙钟跨过观察到的到期时间；日志须显示检查前过期、自动恢复、检查后有效期推进。
3. 独立验证同 Bot 消息会话 API，检查重复动作、失败重试、锁和进程状态。
4. 此后再进入提前续期的后续真实周期。不能用撤权、假时钟或人工代点补齐证据。

任意桌面导航仍未解决。常驻部署必须明确依赖权限页已开或正确链接可见；入口丢失、桌面不可操作、
睡眠或服务停止都必须作为实际中断记录，不能把中断前后拼成无人值守认证。
具体部署与观察是否已启动，以 `docs/status.md` 的最新记录为准；本节定义验收条件，不宣称未来周期通过。
