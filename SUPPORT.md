# Support

wecom-agent-gateway is a community project in Public Preview.

- Usage questions and reproducible bugs: GitHub Issues.
- Design proposals and new adapters: GitHub Issues before a large pull request.
- Vulnerabilities: private GitHub Security Advisory, as described in
  [SECURITY.md](SECURITY.md).
- Tencent WeCom account, Bot provisioning, or official service issues: use
  Tencent WeCom's official support channels.
- Codex, Kimi, OpenClaw, Pi, or model-provider account issues: use the relevant
  upstream project's support channel.

Please do not post credentials, internal IDs, real employee or conversation
names, message contents, media URLs, or private logs.
